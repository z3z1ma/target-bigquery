# 0.8.0 release candidate — publication blocked

Publication to PyPI (`z3-target-bigquery`) and GitHub is authorized only after
validation passes. This branch prepares version0.8.0; it is not a release.
The required live overwrite regression remains blocked on separate authorization
for generated data, temporary BigQuery tables and up to $1 usage. #152 must be
reconciled with current main, tested twice for batch_job and storage_write_api,
and verified for rows/layout after each overwrite before inclusion and release.
Current main still has #134's default partitioned-overwrite failure. Do not publish
this candidate with that known regression. Rebuild artifacts after the fix lands.

## Merged changes to include in release notes

Since tag 0.7.2, main contains these user-visible changes (contributor commits
remain in Git history):

- Storage Write JSON serialization for nested/repeated fields, input preservation,
  numeric rejection and type checks (#160, retaining Lautaro Celli's #140 work).
- Durable Storage Write checkpoints: MERGE completes before state, staging rotates
  correctly, and commit response errors prevent acknowledgement (#153).
- Overwrite STATE is deferred until EOF publication succeeds. Termination avoids
  initiating partial snapshot publication; mixed-stream replay and upstream EOF
  limitations are documented (#156).
- Bounded query submission/result waits, including view creation, plus job
  diagnostics without record payloads (#157, retaining Dana Arsovska's #149 work).
- Lossy column transform collisions are rejected with stream/path diagnostics;
  schema-only suffixing is removed (#162). Existing pipelines that depended on
  ambiguous transformed names must rename source keys or change transforms.
- Earlier merged fixes include nested protobuf support, streaming-insert row
  errors, key/config/view edge cases, transforms for job-based sinks and schema
  changes, temporary-table naming, period replacement, partition expiration,
  physical row ordering during deduplication, and final cleanup metrics
  (`4e2e4ce`, `ceeafca`, `fecd1e8`, `e7a9438`, #119/#122/#123/#112/#100/#95).
- Packaging moved to uv/Hatch with refreshed dependencies and an offline Python
  3.10–3.12 matrix. Action updates retain original Dependabot commits and explicit
  cache pruning (#151/#158).

The existing CHANGELOG is generated by Changie and is incomplete even for 0.7.2;
regenerate the final changelog from merged history when choosing a release. This
candidate groups runtime changes, not every maintenance-only commit.
